# Retail Sales SQL Project

## Project Overview

This project analyzes retail sales data using MySQL to identify sales trends, customer behavior, product performance, regional performance, returns, discounts, and shipping time.

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL
- GitHub

## Dataset

The dataset contains retail order information including:

- Order details
- Customer information
- Product details
- Sales and profit
- Discounts
- Shipping information
- Payment methods
- Customer satisfaction
- Returns
- Order status

## Business Questions

This project answers the following questions:

1. Are there any NULL values in the dataset?
2. Are there any duplicate order IDs?
3. What is the total number of orders, total sales, and total profit?
4. What is the average order value?
5. How many unique customers are there?
6. How are customers distributed by gender?
7. Which product categories generate the highest sales?
8. Which products generate the highest profit?
9. Which product categories have the highest quantity sold?
10. Which regions generate the highest sales?
11. Which cities generate the highest sales?
12. What is the average discount percentage and how does it relate to profit?
13. What is the return rate?
14. Which product categories have the highest average shipping time?
